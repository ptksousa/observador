## 🛠️ Sobre o Desenvolvimento do Front-end

Meu foco principal de estudo e desenvolvimento neste projeto é o **Back-end (Python/Django)** — estruturando o banco de dados, regras de negócio, segurança e sistema de permissões. 

Para viabilizar a interface visual de forma ágil e focar no que importa para o meu aprendizado, o código Front-end (HTML, CSS e scripts de UI) foi gerado com o auxílio de Inteligência Artificial. Toda a integração desses templates com o motor do Django, validações e lógicas de rotas foram feitas manualmente por mim.
